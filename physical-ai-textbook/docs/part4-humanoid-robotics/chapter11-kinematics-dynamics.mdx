## Introduction

**Humanoid robotics** demands precise mathematical models to control complex kinematic chains with 20+ degrees of freedom (DOF). Unlike wheeled robots that navigate on 2D planes, humanoids must coordinate arms, legs, torso, and head in 3D space while maintaining balance and executing tasks.

**Why Kinematics & Dynamics Matter:**
- **Task Execution:** "Move hand to position (0.5, 0.3, 0.8)" requires inverse kinematics
- **Collision Avoidance:** Know where every link is in 3D space
- **Force Control:** Apply precise forces for manipulation (opening doors, grasping objects)
- **Balance:** Compute center of mass (CoM) and zero moment point (ZMP) for stability
- **Energy Efficiency:** Minimize torques and accelerations

**Real-World Applications:**
- Humanoid assistants (Tesla Optimus, Boston Dynamics Atlas)
- Industrial manipulators (UR5, KUKA iiwa)
- Medical robots (da Vinci surgical system)
- Service robots (SoftBank Pepper, Toyota HSR)

## Kinematic Fundamentals

### Degrees of Freedom (DOF)

**DOF** = number of independent motions a robot can execute

**Examples:**
- **Human arm:** 7 DOF (shoulder: 3, elbow: 1, wrist: 3)
- **UR5 arm:** 6 DOF (all revolute joints)
- **Full humanoid:** 20-40 DOF (Atlas: 28 DOF)

**Redundant vs. Non-Redundant:**
- **6 DOF:** Just enough to reach any pose (position + orientation) in 3D
- **7+ DOF:** Redundant → Multiple solutions exist for same end-effector pose

### Denavit-Hartenberg (DH) Parameters

**DH Convention** provides a systematic way to assign coordinate frames to each joint and describe the transformation between them.

**Four Parameters per Joint:**

| Parameter | Symbol | Description |
|-----------|--------|-------------|
| Link length | $a_i$ | Distance along $x_i$ from $z_{i-1}$ to $z_i$ |
| Link twist | $\alpha_i$ | Angle around $x_i$ from $z_{i-1}$ to $z_i$ |
| Link offset | $d_i$ | Distance along $z_{i-1}$ from $x_{i-1}$ to $x_i$ |
| Joint angle | $\theta_i$ | Angle around $z_{i-1}$ from $x_{i-1}$ to $x_i$ |

**For revolute joint:** $\theta_i$ is variable, $d_i$ is fixed
**For prismatic joint:** $d_i$ is variable, $\theta_i$ is fixed

### Homogeneous Transformation Matrix

The transformation from frame $i-1$ to frame $i$:

$$
T_i^{i-1} =
\begin{bmatrix}
\cos\theta_i & -\sin\theta_i \cos\alpha_i & \sin\theta_i \sin\alpha_i & a_i \cos\theta_i \\
\sin\theta_i & \cos\theta_i \cos\alpha_i & -\cos\theta_i \sin\alpha_i & a_i \sin\theta_i \\
0 & \sin\alpha_i & \cos\alpha_i & d_i \\
0 & 0 & 0 & 1
\end{bmatrix}
$$

**Chain transformation to end-effector:**

$$
T_n^0 = T_1^0 \cdot T_2^1 \cdot \ldots \cdot T_n^{n-1}
$$

## Forward Kinematics (FK)

**Problem:** Given joint angles $\mathbf{q} = [\theta_1, \theta_2, \ldots, \theta_n]$, find end-effector pose $(x, y, z, roll, pitch, yaw)$

**Solution:** Multiply transformation matrices

### Example: 2-DOF Planar Arm

```
Link 1: Length L1 = 1.0m, θ1 variable
Link 2: Length L2 = 0.8m, θ2 variable
```

**DH Table:**

| Joint | $a_i$ | $\alpha_i$ | $d_i$ | $\theta_i$ |
|-------|-------|------------|-------|------------|
| 1     | L1    | 0          | 0     | $\theta_1$ |
| 2     | L2    | 0          | 0     | $\theta_2$ |

**Forward Kinematics:**

$$
x = L_1 \cos\theta_1 + L_2 \cos(\theta_1 + \theta_2)
$$

$$
y = L_1 \sin\theta_1 + L_2 \sin(\theta_1 + \theta_2)
$$

### Python Implementation

```python
#!/usr/bin/env python3
import numpy as np
import matplotlib.pyplot as plt

class PlanarArm:
    def __init__(self, link_lengths):
        self.L = link_lengths  # [L1, L2, ...]

    def forward_kinematics(self, joint_angles):
        """
        Compute end-effector position given joint angles

        Args:
            joint_angles: [θ1, θ2, ...] in radians

        Returns:
            (x, y): End-effector position
        """
        x = 0.0
        y = 0.0
        angle_sum = 0.0

        for L, theta in zip(self.L, joint_angles):
            angle_sum += theta
            x += L * np.cos(angle_sum)
            y += L * np.sin(angle_sum)

        return x, y

    def plot_arm(self, joint_angles):
        """Visualize arm configuration"""
        x_pos = [0]
        y_pos = [0]
        angle_sum = 0.0

        # Compute all joint positions
        for L, theta in zip(self.L, joint_angles):
            angle_sum += theta
            x_pos.append(x_pos[-1] + L * np.cos(angle_sum))
            y_pos.append(y_pos[-1] + L * np.sin(angle_sum))

        # Plot
        plt.figure(figsize=(8, 8))
        plt.plot(x_pos, y_pos, 'o-', linewidth=3, markersize=10)
        plt.plot(x_pos[0], y_pos[0], 'go', markersize=15, label='Base')
        plt.plot(x_pos[-1], y_pos[-1], 'ro', markersize=15, label='End-effector')

        plt.xlim(-2, 2)
        plt.ylim(-2, 2)
        plt.grid(True)
        plt.axis('equal')
        plt.xlabel('X (m)')
        plt.ylabel('Y (m)')
        plt.title('2-DOF Planar Arm')
        plt.legend()
        plt.show()

# Example usage
if __name__ == '__main__':
    arm = PlanarArm([1.0, 0.8])  # 2-link arm

    # Test configuration: θ1=45°, θ2=30°
    q = [np.deg2rad(45), np.deg2rad(30)]
    x, y = arm.forward_kinematics(q)

    print(f"Joint angles: θ1={q[0]:.2f}, θ2={q[1]:.2f} rad")
    print(f"End-effector position: ({x:.3f}, {y:.3f})")

    arm.plot_arm(q)
```

**Output:**
```
Joint angles: θ1=0.79, θ2=0.52 rad
End-effector position: (1.414, 1.157)
```

## Inverse Kinematics (IK)

**Problem:** Given desired end-effector pose, find joint angles $\mathbf{q}$

**Challenge:**
- No closed-form solution for n > 3 DOF
- Multiple solutions may exist (redundancy)
- Some poses unreachable (workspace limits)

### Analytical IK (2-DOF Example)

**Given:** Target position $(x_d, y_d)$

**Solve:**

1. **Distance to target:**
   $$
   r = \sqrt{x_d^2 + y_d^2}
   $$

2. **Elbow angle $\theta_2$ (using law of cosines):**
   $$
   \cos\theta_2 = \frac{r^2 - L_1^2 - L_2^2}{2 L_1 L_2}
   $$

   $$
   \theta_2 = \pm \arccos\left(\frac{r^2 - L_1^2 - L_2^2}{2 L_1 L_2}\right)
   $$

   **Two solutions:** Elbow up (+) or elbow down (-)

3. **Shoulder angle $\theta_1$:**
   $$
   \theta_1 = \arctan2(y_d, x_d) - \arctan2(L_2 \sin\theta_2, L_1 + L_2 \cos\theta_2)
   $$

### Python Implementation

```python
import numpy as np

class PlanarArmIK(PlanarArm):
    def inverse_kinematics(self, target_x, target_y, elbow_up=True):
        """
        Compute joint angles for target position

        Args:
            target_x, target_y: Desired end-effector position
            elbow_up: True for elbow-up solution, False for elbow-down

        Returns:
            [θ1, θ2] in radians, or None if unreachable
        """
        L1, L2 = self.L

        # Distance to target
        r = np.sqrt(target_x**2 + target_y**2)

        # Check if target is reachable
        if r > (L1 + L2) or r < abs(L1 - L2):
            print(f"Target ({target_x:.2f}, {target_y:.2f}) unreachable! (r={r:.2f})")
            return None

        # Elbow angle (law of cosines)
        cos_theta2 = (r**2 - L1**2 - L2**2) / (2 * L1 * L2)
        cos_theta2 = np.clip(cos_theta2, -1.0, 1.0)  # Numerical stability

        if elbow_up:
            theta2 = np.arccos(cos_theta2)
        else:
            theta2 = -np.arccos(cos_theta2)

        # Shoulder angle
        k1 = L1 + L2 * np.cos(theta2)
        k2 = L2 * np.sin(theta2)
        theta1 = np.arctan2(target_y, target_x) - np.arctan2(k2, k1)

        return [theta1, theta2]

# Example usage
if __name__ == '__main__':
    arm = PlanarArmIK([1.0, 0.8])

    # Target position
    target = (1.2, 0.9)

    # Solve IK (elbow-up)
    q_up = arm.inverse_kinematics(target[0], target[1], elbow_up=True)
    print(f"Elbow-up solution: θ1={np.rad2deg(q_up[0]):.1f}°, θ2={np.rad2deg(q_up[1]):.1f}°")

    # Verify FK
    x, y = arm.forward_kinematics(q_up)
    print(f"FK verification: ({x:.3f}, {y:.3f}) vs target ({target[0]}, {target[1]})")

    # Solve IK (elbow-down)
    q_down = arm.inverse_kinematics(target[0], target[1], elbow_up=False)
    print(f"Elbow-down solution: θ1={np.rad2deg(q_down[0]):.1f}°, θ2={np.rad2deg(q_down[1]):.1f}°")
```

**Output:**
```
Elbow-up solution: θ1=36.0°, θ2=64.3°
FK verification: (1.200, 0.900) vs target (1.2, 0.9)
Elbow-down solution: θ1=84.3°, θ2=-64.3°
```

## Numerical IK (Jacobian-Based)

For robots with n > 3 DOF, use **Jacobian pseudoinverse** method:

### Jacobian Matrix

**Jacobian** relates joint velocities $\dot{\mathbf{q}}$ to end-effector velocity $\mathbf{v}$:

$$
\mathbf{v} = J(\mathbf{q}) \dot{\mathbf{q}}
$$

Where:
- $\mathbf{v} = [v_x, v_y, v_z, \omega_x, \omega_y, \omega_z]^T$ (6D velocity)
- $J$ is $6 \times n$ matrix
- $\dot{\mathbf{q}} = [\dot{\theta}_1, \ldots, \dot{\theta}_n]^T$ (joint velocities)

### Iterative IK Algorithm

```python
def ik_jacobian_pseudoinverse(self, target_pose, q_init, max_iter=100, tol=1e-3):
    """
    Numerical IK using Jacobian pseudoinverse

    Args:
        target_pose: [x, y, z, roll, pitch, yaw]
        q_init: Initial guess for joint angles
        max_iter: Maximum iterations
        tol: Position error tolerance (meters)

    Returns:
        Joint angles that achieve target pose
    """
    q = np.array(q_init)

    for iteration in range(max_iter):
        # 1. Compute current end-effector pose
        current_pose = self.forward_kinematics(q)

        # 2. Compute error
        error = np.array(target_pose) - np.array(current_pose)
        error_norm = np.linalg.norm(error[:3])  # Position error only

        if error_norm < tol:
            print(f"Converged in {iteration} iterations")
            return q

        # 3. Compute Jacobian
        J = self.compute_jacobian(q)

        # 4. Compute joint velocity using pseudoinverse
        J_pinv = np.linalg.pinv(J)  # Moore-Penrose pseudoinverse
        dq = J_pinv @ error

        # 5. Update joint angles
        alpha = 0.1  # Step size (tune for stability)
        q = q + alpha * dq

        # 6. Apply joint limits
        q = np.clip(q, self.q_min, self.q_max)

    print(f"Did not converge after {max_iter} iterations (error: {error_norm:.4f})")
    return q
```

### Damped Least Squares (Singularity-Robust)

Near singularities (Jacobian rank-deficient), use **damped least squares**:

$$
\dot{\mathbf{q}} = J^T (J J^T + \lambda^2 I)^{-1} \mathbf{v}
$$

Where $\lambda$ is damping factor (e.g., 0.01-0.1)

```python
# Replace pseudoinverse line with:
lambda_damping = 0.05
J_dls = J.T @ np.linalg.inv(J @ J.T + lambda_damping**2 * np.eye(6))
dq = J_dls @ error
```

## Jacobian Computation

### Numerical Jacobian (Finite Differences)

```python
def compute_jacobian_numerical(self, q, delta=1e-6):
    """
    Compute Jacobian using finite differences

    Args:
        q: Current joint angles
        delta: Step size for numerical differentiation

    Returns:
        6xN Jacobian matrix
    """
    n = len(q)
    J = np.zeros((6, n))

    # Current pose
    pose_0 = self.forward_kinematics(q)

    # Perturb each joint and compute change in pose
    for i in range(n):
        q_perturbed = q.copy()
        q_perturbed[i] += delta
        pose_i = self.forward_kinematics(q_perturbed)

        # Finite difference approximation
        J[:, i] = (np.array(pose_i) - np.array(pose_0)) / delta

    return J
```

### Analytical Jacobian (Faster, Exact)

For revolute joint $i$ with axis $\mathbf{z}_i$ and position $\mathbf{p}_i$:

$$
J_v^i = \mathbf{z}_i \times (\mathbf{p}_{\text{ee}} - \mathbf{p}_i)
$$

$$
J_\omega^i = \mathbf{z}_i
$$

Where:
- $J_v^i$ = linear velocity contribution (3x1)
- $J_\omega^i$ = angular velocity contribution (3x1)
- $\mathbf{p}_{\text{ee}}$ = end-effector position

```python
def compute_jacobian_analytical(self, q):
    """Analytical Jacobian for serial manipulator"""
    n = len(q)
    J = np.zeros((6, n))

    # Compute all transformation matrices
    T = [np.eye(4)]  # Base frame
    for i in range(n):
        T.append(T[-1] @ self.dh_matrix(i, q[i]))

    # End-effector position
    p_ee = T[-1][:3, 3]

    # Compute Jacobian columns
    for i in range(n):
        z_i = T[i][:3, 2]  # Z-axis of frame i
        p_i = T[i][:3, 3]  # Origin of frame i

        # Linear velocity
        J[:3, i] = np.cross(z_i, p_ee - p_i)

        # Angular velocity
        J[3:, i] = z_i

    return J
```

## Dynamics: Forces and Torques

### Equations of Motion

**Manipulator dynamics** (Lagrangian formulation):

$$
\mathbf{M}(\mathbf{q}) \ddot{\mathbf{q}} + \mathbf{C}(\mathbf{q}, \dot{\mathbf{q}}) \dot{\mathbf{q}} + \mathbf{g}(\mathbf{q}) = \boldsymbol{\tau}
$$

Where:
- $\mathbf{M}(\mathbf{q})$ = Mass/inertia matrix (nxn)
- $\mathbf{C}(\mathbf{q}, \dot{\mathbf{q}})$ = Coriolis and centrifugal forces (nxn)
- $\mathbf{g}(\mathbf{q})$ = Gravity torques (n)
- $\boldsymbol{\tau}$ = Joint torques (control input)

### Forward Dynamics

**Given:** Joint torques $\boldsymbol{\tau}$
**Find:** Joint accelerations $\ddot{\mathbf{q}}$

$$
\ddot{\mathbf{q}} = \mathbf{M}^{-1}(\mathbf{q}) \left[\boldsymbol{\tau} - \mathbf{C}(\mathbf{q}, \dot{\mathbf{q}}) \dot{\mathbf{q}} - \mathbf{g}(\mathbf{q})\right]
$$

**Use case:** Physics simulation (Gazebo, Isaac Sim)

### Inverse Dynamics

**Given:** Desired trajectory $\mathbf{q}(t), \dot{\mathbf{q}}(t), \ddot{\mathbf{q}}(t)$
**Find:** Required torques $\boldsymbol{\tau}(t)$

$$
\boldsymbol{\tau} = \mathbf{M}(\mathbf{q}) \ddot{\mathbf{q}} + \mathbf{C}(\mathbf{q}, \dot{\mathbf{q}}) \dot{\mathbf{q}} + \mathbf{g}(\mathbf{q})
$$

**Use case:** Feedforward control, trajectory optimization

### Example: IK with MoveIt2

```python
#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import PoseStamped
from moveit_msgs.srv import GetPositionIK

class IKSolver(Node):
    def __init__(self):
        super().__init__('ik_solver')
        self.ik_client = self.create_client(GetPositionIK, '/compute_ik')
        while not self.ik_client.wait_for_service(timeout_sec=1.0):
            self.get_logger().info('Waiting for IK service...')

        self.get_logger().info('IK service ready!')

    def compute_ik(self, x, y, z):
        """Compute IK for target position"""
        request = GetPositionIK.Request()
        request.ik_request.group_name = 'panda_arm'
        request.ik_request.robot_state.is_diff = True

        # Target pose
        pose = PoseStamped()
        pose.header.frame_id = 'panda_link0'
        pose.pose.position.x = x
        pose.pose.position.y = y
        pose.pose.position.z = z
        pose.pose.orientation.w = 1.0

        request.ik_request.pose_stamped = pose
        request.ik_request.timeout.sec = 5

        # Call service
        future = self.ik_client.call_async(request)
        rclpy.spin_until_future_complete(self, future)

        response = future.result()
        if response.error_code.val == 1:  # SUCCESS
            joint_names = response.solution.joint_state.name
            joint_positions = response.solution.joint_state.position
            self.get_logger().info('IK Solution:')
            for name, pos in zip(joint_names, joint_positions):
                self.get_logger().info(f'  {name}: {pos:.3f} rad ({np.rad2deg(pos):.1f}°)')
        else:
            self.get_logger().error(f'IK failed with error code: {response.error_code.val}')

def main(args=None):
    rclpy.init(args=args)
    solver = IKSolver()

    # Test IK for position (0.5, 0.2, 0.6)
    solver.compute_ik(0.5, 0.2, 0.6)

    solver.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

## Best Practices

### 1. Joint Limits

Always enforce joint limits:

```python
q = np.clip(q, self.q_min, self.q_max)
```

### 2. Singularity Avoidance

Detect singularities by checking Jacobian rank:

```python
det_J = np.linalg.det(J @ J.T)
if abs(det_J) < 1e-4:
    print("Warning: Near singularity!")
```

### 3. Workspace Analysis

Precompute reachable workspace for fast feasibility checks:

```python
def compute_workspace(self, resolution=0.05):
    """Discretize workspace into voxel grid"""
    workspace = set()

    # Sample all joint configurations
    for q in self.sample_configurations(1000):
        x, y, z = self.forward_kinematics(q)[:3]
        voxel = (round(x/resolution), round(y/resolution), round(z/resolution))
        workspace.add(voxel)

    return workspace
```

### 4. Energy-Optimal Redundancy Resolution

For redundant manipulators, choose solution minimizing joint torques:

```python
# Null-space projection for redundancy
N = np.eye(n) - J_pinv @ J  # Null-space projector
q_null = N @ q_preferred     # Project preferred config into null-space
dq = J_pinv @ error + N @ q_null
```
