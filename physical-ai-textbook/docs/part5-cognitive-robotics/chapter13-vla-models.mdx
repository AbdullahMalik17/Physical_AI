## Introduction

**Vision-Language-Action (VLA) models** represent the frontier of embodied AI, enabling robots to understand natural language commands, perceive their environment through vision, and execute complex manipulation tasks—all through a single end-to-end learned model.

**Why VLA for Physical AI?**
- **Natural Interaction:** "Pick up the red mug and place it on the table" → robot executes
- **Zero-Shot Generalization:** No task-specific programming needed
- **Multimodal Understanding:** Combine vision, language, and proprioception
- **Common Sense Reasoning:** Leverage pre-trained knowledge from billions of text/image pairs
- **Rapid Deployment:** Train once, deploy across robot platforms

**Breakthrough Models (2023-2024):**
- **RT-2 (Google DeepMind):** 55B parameter VLA, 6x better generalization than RT-1
- **PaLM-E (Google):** 562B parameter embodied multimodal LLM
- **OpenVLA (Stanford, UC Berkeley):** 7B open-source VLA model
- **RoboFlamingo (Microsoft):** Few-shot learning for manipulation

**Real-World Impact:**
- Warehouse robots that understand "Move the fragile boxes to the left shelf"
- Service robots: "Bring me a cold drink from the fridge"
- Manufacturing: "Inspect the circuit board for defects and report"

## Architecture Overview

### VLA Model Pipeline

```
┌────────────────────────────────────────────────────────────┐
│         Vision-Language-Action (VLA) Model                 │
├────────────────────────────────────────────────────────────┤
│  Input Modalities                                          │
│  ├─ Vision: RGB-D Camera (224x224)                        │
│  ├─ Language: Natural language instruction                │
│  ├─ Proprioception: Joint angles, gripper state           │
│  └─ Audio (optional): Speech input via Whisper            │
├────────────────────────────────────────────────────────────┤
│  Encoder (Multimodal Fusion)                               │
│  ├─ Vision Encoder: ViT (Vision Transformer)              │
│  ├─ Language Encoder: T5 or BERT                          │
│  └─ Fusion Module: Cross-attention between vision & text   │
├────────────────────────────────────────────────────────────┤
│  Policy Network (Action Prediction)                        │
│  ├─ Transformer Decoder                                    │
│  ├─ Action Tokenization (discretize continuous actions)   │
│  └─ Output: 7-DOF end-effector pose + gripper command     │
├────────────────────────────────────────────────────────────┤
│  Low-Level Controller (ROS 2 Integration)                  │
│  ├─ Inverse Kinematics (MoveIt2)                          │
│  ├─ Trajectory Execution                                   │
│  └─ Feedback Loop (visual servoing, force control)        │
└────────────────────────────────────────────────────────────┘
```

**Key Innovation:** Instead of separate perception + planning + control modules, VLA learns an end-to-end mapping from pixels + language → robot actions.

## Voice-to-Action Pipeline

### 1. Speech Recognition with Whisper

**OpenAI Whisper** provides state-of-the-art automatic speech recognition (ASR) with multilingual support.

```python
#!/usr/bin/env python3
import whisper
import pyaudio
import wave
import numpy as np

class VoiceCommandListener:
    def __init__(self, model_size="base"):
        # Load Whisper model (tiny, base, small, medium, large)
        self.model = whisper.load_model(model_size)
        print(f"Whisper model '{model_size}' loaded!")

    def record_audio(self, duration=5, sample_rate=16000):
        """Record audio from microphone"""
        print("🎤 Listening...")

        p = pyaudio.PyAudio()
        stream = p.open(
            format=pyaudio.paInt16,
            channels=1,
            rate=sample_rate,
            input=True,
            frames_per_buffer=1024
        )

        frames = []
        for _ in range(0, int(sample_rate / 1024 * duration)):
            data = stream.read(1024)
            frames.append(data)

        stream.stop_stream()
        stream.close()
        p.terminate()

        # Convert to numpy array
        audio_data = np.frombuffer(b''.join(frames), dtype=np.int16)
        audio_data = audio_data.astype(np.float32) / 32768.0  # Normalize to [-1, 1]

        return audio_data

    def transcribe(self, audio_data):
        """Transcribe audio to text using Whisper"""
        result = self.model.transcribe(audio_data, language='en')
        return result['text']

    def listen_for_command(self):
        """Listen and return transcribed command"""
        audio = self.record_audio(duration=5)
        command = self.transcribe(audio)
        print(f"💬 Heard: \"{command}\"")
        return command

# Example usage
if __name__ == '__main__':
    listener = VoiceCommandListener(model_size="base")

    while True:
        command = listener.listen_for_command()

        if "stop" in command.lower():
            print("🛑 Shutting down...")
            break

        # Send command to robot (next step)
        print(f"🤖 Executing: {command}")
```

## LLM Integration for Cognitive Planning

### 2. Natural Language Understanding with GPT-4

**Challenge:** Converting natural language → robot actions requires:
- Task decomposition ("clean the table" → grasp object → move to bin → release)
- Object grounding ("the red mug" → pixel coordinates)
- Common sense reasoning ("fragile" → gentle grasp force)

### GPT-4 as Task Planner

```python
import openai
import json

class LLMTaskPlanner:
    def __init__(self, api_key):
        openai.api_key = api_key
        self.system_prompt = """You are a robot task planner. Given a natural language command,
break it down into a sequence of primitive robot actions.

Available actions:
- move_to(object_name) - Move arm to object
- grasp(object_name, force) - Close gripper (force: gentle/normal/firm)
- place(location) - Open gripper at location
- navigate_to(location) - Move base to location
- inspect(object_name) - Look at object with camera

Output JSON array of actions with parameters."""

    def plan_task(self, user_command, scene_description):
        """Convert natural language to action sequence"""

        messages = [
            {"role": "system", "content": self.system_prompt},
            {"role": "user", "content": f"""Scene: {scene_description}

Command: {user_command}

Generate action sequence:"""}
        ]

        response = openai.ChatCompletion.create(
            model="gpt-4-turbo-preview",
            messages=messages,
            response_format={"type": "json_object"},
            temperature=0.2  # Low temp for deterministic planning
        )

        plan = json.loads(response.choices[0].message.content)
        return plan['actions']

# Example usage
if __name__ == '__main__':
    planner = LLMTaskPlanner(api_key="sk-...")

    # Scene from vision system
    scene = """Objects detected:
- Red ceramic mug (ID: obj_001) at position (0.5, 0.3, 0.8)
- Blue plastic cup (ID: obj_002) at position (0.6, 0.2, 0.8)
- Table surface at height 0.75m
- Trash bin at position (1.0, -0.5, 0.0)
"""

    command = "Pick up the red mug carefully and throw it away"

    actions = planner.plan_task(command, scene)

    print("📋 Generated Plan:")
    for i, action in enumerate(actions):
        print(f"{i+1}. {action}")

# Example output:
# 1. {'action': 'move_to', 'object': 'obj_001'}
# 2. {'action': 'grasp', 'object': 'obj_001', 'force': 'gentle'}
# 3. {'action': 'navigate_to', 'location': 'trash_bin'}
# 4. {'action': 'place', 'location': 'trash_bin'}
```

## Vision-Language Grounding

### 3. Object Detection with Vision-Language Models

**CLIP (Contrastive Language-Image Pre-training)** enables zero-shot object detection using natural language.

```python
import torch
import clip
from PIL import Image
import numpy as np

class VisionLanguageGrounder:
    def __init__(self):
        self.device = "cuda" if torch.cuda.is_available() else "cpu"
        self.model, self.preprocess = clip.load("ViT-B/32", device=self.device)

    def find_object(self, image_path, text_query):
        """
        Find object in image matching text description

        Args:
            image_path: Path to RGB image
            text_query: Natural language description (e.g., "red mug")

        Returns:
            bounding_box: [x_min, y_min, x_max, y_max]
            confidence: similarity score
        """
        # Load image
        image = Image.open(image_path).convert('RGB')
        image_input = self.preprocess(image).unsqueeze(0).to(self.device)

        # Prepare text query
        text_input = clip.tokenize([text_query]).to(self.device)

        # Compute similarity
        with torch.no_grad():
            image_features = self.model.encode_image(image_input)
            text_features = self.model.encode_text(text_input)

            # Cosine similarity
            similarity = (image_features @ text_features.T).item()

        # For actual localization, use OWL-ViT or Grounding DINO
        # Here we return placeholder bbox
        return [100, 100, 200, 200], similarity

    def ground_text_to_3d(self, text_query, rgb_image, depth_image, camera_intrinsics):
        """
        Convert text query to 3D position in robot frame

        Args:
            text_query: "the red mug"
            rgb_image: RGB image (H x W x 3)
            depth_image: Depth map (H x W)
            camera_intrinsics: 3x3 matrix [fx, 0, cx; 0, fy, cy; 0, 0, 1]

        Returns:
            position_3d: [x, y, z] in meters
        """
        # Step 1: Find object in image
        bbox, confidence = self.find_object_bbox(rgb_image, text_query)

        if confidence < 0.3:
            raise ValueError(f"Object '{text_query}' not found (confidence={confidence:.2f})")

        # Step 2: Get depth at bbox center
        cx = (bbox[0] + bbox[2]) // 2
        cy = (bbox[1] + bbox[3]) // 2
        depth = depth_image[cy, cx]

        # Step 3: Project to 3D using camera intrinsics
        fx = camera_intrinsics[0, 0]
        fy = camera_intrinsics[1, 1]
        cx_cam = camera_intrinsics[0, 2]
        cy_cam = camera_intrinsics[1, 2]

        x = (cx - cx_cam) * depth / fx
        y = (cy - cy_cam) * depth / fy
        z = depth

        return np.array([x, y, z])

    def find_object_bbox(self, image, text_query):
        """Use Grounding DINO for actual object detection"""
        # Placeholder - integrate Grounding DINO or OWL-ViT
        from groundingdino.util.inference import Model

        model = Model(
            model_config_path="GroundingDINO/groundingdino/config/GroundingDINO_SwinT_OGC.py",
            model_checkpoint_path="weights/groundingdino_swint_ogc.pth"
        )

        detections = model.predict_with_classes(
            image=image,
            classes=[text_query],
            box_threshold=0.35,
            text_threshold=0.25
        )

        if len(detections.xyxy) == 0:
            return None, 0.0

        # Return first detection
        bbox = detections.xyxy[0]  # [x_min, y_min, x_max, y_max]
        confidence = detections.confidence[0]

        return bbox, confidence
```

## End-to-End VLA Model Training

### 4. RT-2 Style Architecture

```python
import torch
import torch.nn as nn
from transformers import T5ForConditionalGeneration, T5Tokenizer

class VLAModel(nn.Module):
    """Vision-Language-Action Model (RT-2 inspired)"""

    def __init__(self, vision_encoder, language_model, action_dim=7):
        super().__init__()

        # Vision encoder (ViT or ResNet)
        self.vision_encoder = vision_encoder  # Output: 256-dim embeddings

        # Language encoder (T5)
        self.language_model = language_model

        # Action prediction head
        self.action_head = nn.Sequential(
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Linear(256, action_dim)
        )

    def forward(self, image, text, proprioception):
        """
        Forward pass

        Args:
            image: (B, 3, 224, 224) RGB image
            text: (B, max_len) tokenized instruction
            proprioception: (B, 7) current joint angles

        Returns:
            action: (B, 7) predicted joint velocities
        """
        # Encode image
        visual_features = self.vision_encoder(image)  # (B, 256)

        # Encode text
        text_features = self.language_model.encoder(text).last_hidden_state
        text_features = text_features.mean(dim=1)  # (B, 512)

        # Concatenate all features
        combined = torch.cat([visual_features, text_features, proprioception], dim=1)

        # Predict action
        action = self.action_head(combined)

        return action

# Training loop
def train_vla(model, dataloader, optimizer, num_epochs=100):
    """Train VLA model with behavior cloning"""

    criterion = nn.MSELoss()

    for epoch in range(num_epochs):
        total_loss = 0

        for batch in dataloader:
            image = batch['image'].to(device)
            text = batch['text'].to(device)
            proprioception = batch['proprioception'].to(device)
            action_gt = batch['action'].to(device)

            # Forward pass
            action_pred = model(image, text, proprioception)

            # Compute loss
            loss = criterion(action_pred, action_gt)

            # Backward pass
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()

            total_loss += loss.item()

        print(f"Epoch {epoch+1}/{num_epochs}, Loss: {total_loss/len(dataloader):.4f}")
```

### 5. Data Collection for VLA

**Teleoperation Setup:**

```python
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image, JointState
from geometry_msgs.msg import Twist
from cv_bridge import CvBridge
import h5py

class TeleoperationRecorder(Node):
    def __init__(self):
        super().__init__('teleoperation_recorder')

        # Subscribers
        self.image_sub = self.create_subscription(
            Image, '/camera/image_raw', self.image_callback, 10)
        self.joint_sub = self.create_subscription(
            JointState, '/joint_states', self.joint_callback, 10)

        # Data buffer
        self.trajectories = []
        self.current_trajectory = {
            'images': [],
            'joints': [],
            'actions': [],
            'language': ""
        }

        self.bridge = CvBridge()
        self.recording = False

    def start_trajectory(self, language_command):
        """Start recording new trajectory"""
        self.recording = True
        self.current_trajectory = {
            'images': [],
            'joints': [],
            'actions': [],
            'language': language_command
        }
        self.get_logger().info(f"📹 Recording: '{language_command}'")

    def stop_trajectory(self):
        """Stop and save trajectory"""
        self.recording = False
        self.trajectories.append(self.current_trajectory.copy())
        self.get_logger().info(f"✅ Saved trajectory ({len(self.current_trajectory['images'])} frames)")

    def image_callback(self, msg):
        if not self.recording:
            return

        # Convert ROS Image to numpy
        image = self.bridge.imgmsg_to_cv2(msg, desired_encoding='rgb8')
        self.current_trajectory['images'].append(image)

    def joint_callback(self, msg):
        if not self.recording:
            return

        self.current_trajectory['joints'].append(msg.position)

    def save_dataset(self, filename):
        """Save all trajectories to HDF5"""
        with h5py.File(filename, 'w') as f:
            for i, traj in enumerate(self.trajectories):
                grp = f.create_group(f'trajectory_{i}')
                grp.create_dataset('images', data=np.array(traj['images']))
                grp.create_dataset('joints', data=np.array(traj['joints']))
                grp.create_dataset('actions', data=np.array(traj['actions']))
                grp.attrs['language'] = traj['language']

        self.get_logger().info(f"💾 Saved {len(self.trajectories)} trajectories to {filename}")

# Usage
def main(args=None):
    rclpy.init(args=args)
    recorder = TeleoperationRecorder()

    # Record 100 demonstrations
    commands = [
        "Pick up the red block",
        "Move the cup to the left",
        "Stack the blue block on the green block",
        # ... more tasks
    ]

    for cmd in commands:
        input(f"Press ENTER to start: {cmd}")
        recorder.start_trajectory(cmd)
        input("Press ENTER to stop recording")
        recorder.stop_trajectory()

    recorder.save_dataset('robot_demonstrations.h5')
    rclpy.shutdown()
```

## ROS 2 Integration

### 6. VLA Node for Real Robot

```python
#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image, JointState
from std_msgs.msg import String
from geometry_msgs.msg import Pose
import torch
import numpy as np

class VLAControllerNode(Node):
    def __init__(self):
        super().__init__('vla_controller')

        # Load VLA model
        self.model = self.load_vla_model()
        self.device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
        self.model.to(self.device)
        self.model.eval()

        # Subscribers
        self.image_sub = self.create_subscription(
            Image, '/camera/image_raw', self.image_callback, 10)
        self.joint_sub = self.create_subscription(
            JointState, '/joint_states', self.joint_callback, 10)
        self.command_sub = self.create_subscription(
            String, '/voice_command', self.command_callback, 10)

        # Publishers
        self.action_pub = self.create_publisher(JointState, '/joint_commands', 10)

        # State
        self.current_image = None
        self.current_joints = None
        self.current_command = None

        # Control loop timer (10 Hz)
        self.timer = self.create_timer(0.1, self.control_loop)

    def load_vla_model(self):
        """Load pre-trained VLA model"""
        model = VLAModel(vision_encoder=..., language_model=..., action_dim=7)
        checkpoint = torch.load('vla_model_checkpoint.pth')
        model.load_state_dict(checkpoint['model_state_dict'])
        return model

    def image_callback(self, msg):
        # Convert to numpy and store
        from cv_bridge import CvBridge
        bridge = CvBridge()
        self.current_image = bridge.imgmsg_to_cv2(msg, desired_encoding='rgb8')

    def joint_callback(self, msg):
        self.current_joints = np.array(msg.position)

    def command_callback(self, msg):
        self.current_command = msg.data
        self.get_logger().info(f"🎯 New command: '{self.current_command}'")

    def control_loop(self):
        """Main control loop - run VLA inference at 10 Hz"""
        if self.current_image is None or self.current_joints is None:
            return

        if self.current_command is None:
            return  # Waiting for command

        # Prepare inputs
        image_tensor = self.preprocess_image(self.current_image)
        text_tensor = self.tokenize_text(self.current_command)
        joint_tensor = torch.tensor(self.current_joints, dtype=torch.float32).unsqueeze(0)

        # Run inference
        with torch.no_grad():
            action = self.model(
                image_tensor.to(self.device),
                text_tensor.to(self.device),
                joint_tensor.to(self.device)
            )

        # Publish action
        action_msg = JointState()
        action_msg.header.stamp = self.get_clock().now().to_msg()
        action_msg.name = ['joint1', 'joint2', 'joint3', 'joint4', 'joint5', 'joint6', 'joint7']
        action_msg.velocity = action.cpu().numpy().flatten().tolist()

        self.action_pub.publish(action_msg)

    def preprocess_image(self, image):
        """Resize and normalize image"""
        import torchvision.transforms as T
        transform = T.Compose([
            T.ToPILImage(),
            T.Resize((224, 224)),
            T.ToTensor(),
            T.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
        ])
        return transform(image).unsqueeze(0)

    def tokenize_text(self, text):
        """Tokenize language command"""
        from transformers import T5Tokenizer
        tokenizer = T5Tokenizer.from_pretrained('t5-small')
        tokens = tokenizer(text, return_tensors='pt', padding=True, truncation=True)
        return tokens['input_ids']

def main(args=None):
    rclpy.init(args=args)
    node = VLAControllerNode()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

```python
FORBIDDEN_ACTIONS = [
    "harm", "hit", "throw at person", "break", "damage"
]

def is_safe_command(command):
    """Check if command is safe to execute"""
    command_lower = command.lower()

    for forbidden in FORBIDDEN_ACTIONS:
        if forbidden in command_lower:
            return False, f"Unsafe command detected: '{forbidden}'"

    return True, "Command is safe"
```
