## Introduction

**Isaac ROS** is a collection of hardware-accelerated ROS 2 packages that leverage NVIDIA GPUs to deliver real-time perception capabilities for robots. Built on **CUDA**, **TensorRT**, and **NITROS** (NVIDIA Isaac Transport for ROS), Isaac ROS provides 10-100x speedups compared to CPU-only implementations.

**Why Isaac ROS for Physical AI?**
- **Real-Time Performance:** Sub-10ms latency for critical perception tasks
- **GPU Acceleration:** Leverage CUDA cores, Tensor Cores, and DLA
- **Production-Ready:** Battle-tested in NVIDIA's own robotics platforms
- **Plug-and-Play:** Drop-in replacements for standard ROS 2 packages
- **Zero-Copy:** NITROS eliminates memory copies between nodes

**Supported Platforms:**
- NVIDIA Jetson (Orin, AGX Xavier, Xavier NX)
- NVIDIA GPU (RTX 30/40 series, A-series)
- x86_64 with NVIDIA GPU

### Prerequisites

**1. NVIDIA Jetson (Recommended for robots):**

```bash
# Check Jetson platform
cat /etc/nv_tegra_release

# Expected: Jetson Orin or AGX Xavier
```

**2. Install Isaac ROS (Docker-based):**

```bash
# Clone Isaac ROS Common
cd ~/workspaces
git clone https://github.com/NVIDIA-ISAAC-ROS/isaac_ros_common.git

# Build Docker container with all dependencies
cd isaac_ros_common
./scripts/run_dev.sh

# Inside container, source ROS 2
source /opt/ros/humble/setup.bash
```

**3. Install specific Isaac ROS packages:**

```bash
# Inside Isaac ROS Docker container
cd /workspaces/isaac_ros-dev/src

# Clone Visual SLAM
git clone https://github.com/NVIDIA-ISAAC-ROS/isaac_ros_visual_slam.git

# Build packages
cd /workspaces/isaac_ros-dev
colcon build --symlink-install

source install/setup.bash
```

## Visual SLAM with cuVSLAM

Isaac ROS Visual SLAM (cuVSLAM) provides GPU-accelerated stereo visual odometry and SLAM.

### Launch cuVSLAM with RealSense Camera

```python
"""
visual_slam_launch.py - Launch Isaac ROS Visual SLAM
"""
from launch import LaunchDescription
from launch_ros.actions import Node
from launch.actions import IncludeLaunchDescription
from launch.launch_description_sources import PythonLaunchDescriptionSource
from ament_index_python.packages import get_package_share_directory
import os

def generate_launch_description():
    # RealSense camera node
    realsense_launch = IncludeLaunchDescription(
        PythonLaunchDescriptionSource([
            os.path.join(
                get_package_share_directory('realsense2_camera'),
                'launch', 'rs_launch.py'
            )
        ]),
        launch_arguments={
            'enable_infra1': 'true',
            'enable_infra2': 'true',
            'enable_depth': 'true',
            'depth_module.profile': '640x480x30',
            'enable_gyro': 'true',
            'enable_accel': 'true',
            'unite_imu_method': '1',  # copy mode
        }.items()
    )

    # Visual SLAM node (cuVSLAM)
    visual_slam_node = Node(
        package='isaac_ros_visual_slam',
        executable='isaac_ros_visual_slam',
        name='visual_slam',
        parameters=[{
            # Camera parameters
            'denoise_input_images': True,
            'rectified_images': True,
            'enable_image_denoising': True,
            'enable_imu_fusion': True,

            # SLAM parameters
            'enable_localization_n_mapping': True,
            'enable_observations_view': True,
            'enable_landmarks_view': True,
            'enable_debug_mode': False,

            # Performance
            'num_cameras': 2,  # Stereo
            'min_num_images': 5,
            'image_buffer_size': 40,

            # Map settings
            'enable_slam_visualization': True,
            'enable_debug_imu_mode': False,
            'path_max_size': 1024,

            # GPU
            'gpu_id': 0,
        }],
        remappings=[
            ('stereo_camera/left/image', '/camera/infra1/image_rect_raw'),
            ('stereo_camera/left/camera_info', '/camera/infra1/camera_info'),
            ('stereo_camera/right/image', '/camera/infra2/image_rect_raw'),
            ('stereo_camera/right/camera_info', '/camera/infra2/camera_info'),
            ('visual_slam/imu', '/camera/imu'),
        ],
        output='screen'
    )

    return LaunchDescription([
        realsense_launch,
        visual_slam_node
    ])
```

## Object Detection with RT-DETR

Isaac ROS provides TensorRT-accelerated object detection using RT-DETR (Real-Time Detection Transformer).

### Run RT-DETR Inference

```python
"""
rt_detr_launch.py - Real-time object detection on Jetson/GPU
"""
from launch import LaunchDescription
from launch_ros.actions import Node, ComposableNodeContainer
from launch_ros.descriptions import ComposableNode

def generate_launch_description():
    # RT-DETR DNN Image Encoder (preprocessing)
    encoder_node = ComposableNode(
        package='isaac_ros_dnn_image_encoder',
        plugin='nvidia::isaac_ros::dnn_inference::DnnImageEncoderNode',
        name='dnn_image_encoder',
        parameters=[{
            'network_image_width': 640,
            'network_image_height': 640,
            'image_mean': [0.485, 0.456, 0.406],
            'image_stddev': [0.229, 0.224, 0.225],
        }],
        remappings=[
            ('encoded_tensor', 'tensor_pub'),
            ('image', '/camera/image_raw'),
        ]
    )

    # TensorRT Inference Node
    triton_node = ComposableNode(
        package='isaac_ros_triton',
        plugin='nvidia::isaac_ros::dnn_inference::TritonNode',
        name='triton_inference',
        parameters=[{
            'model_name': 'rtdetr',
            'model_repository_paths': ['/workspaces/models'],
            'max_batch_size': 1,
            'input_tensor_names': ['images'],
            'input_binding_names': ['images'],
            'output_tensor_names': ['labels', 'boxes', 'scores'],
            'output_binding_names': ['labels', 'boxes', 'scores'],
        }]
    )

    # RT-DETR Decoder (postprocessing)
    rtdetr_decoder_node = ComposableNode(
        package='isaac_ros_rtdetr',
        plugin='nvidia::isaac_ros::rtdetr::RtDetrDecoderNode',
        name='rtdetr_decoder',
        parameters=[{
            'confidence_threshold': 0.5,
            'num_classes': 91,  # COCO dataset
        }]
    )

    # Container to run nodes with NITROS zero-copy
    container = ComposableNodeContainer(
        name='rtdetr_container',
        namespace='',
        package='rclcpp_components',
        executable='component_container_mt',  # Multi-threaded
        composable_node_descriptions=[
            encoder_node,
            triton_node,
            rtdetr_decoder_node
        ],
        output='screen'
    )

    return LaunchDescription([container])
```

**Publish Detected Objects:**

```python
"""
detection_publisher.py - Subscribe to detections and publish bounding boxes
"""
import rclpy
from rclpy.node import Node
from vision_msgs.msg import Detection2DArray
from sensor_msgs.msg import Image
from cv_bridge import CvBridge
import cv2
import numpy as np

class DetectionVisualizer(Node):
    def __init__(self):
        super().__init__('detection_visualizer')
        self.bridge = CvBridge()

        # Subscribe to detections
        self.detection_sub = self.create_subscription(
            Detection2DArray,
            '/detections_output',
            self.detection_callback,
            10
        )

        # Subscribe to original image
        self.image_sub = self.create_subscription(
            Image,
            '/camera/image_raw',
            self.image_callback,
            10
        )

        # Publish annotated image
        self.image_pub = self.create_publisher(
            Image,
            '/detections_image',
            10
        )

        self.latest_detections = None
        self.latest_image = None

    def detection_callback(self, msg):
        self.latest_detections = msg.detections

    def image_callback(self, msg):
        self.latest_image = self.bridge.imgmsg_to_cv2(msg, 'bgr8')
        self.visualize_detections()

    def visualize_detections(self):
        if self.latest_image is None or self.latest_detections is None:
            return

        img = self.latest_image.copy()

        for detection in self.latest_detections:
            # Get bounding box
            bbox = detection.bbox
            center_x = int(bbox.center.position.x)
            center_y = int(bbox.center.position.y)
            width = int(bbox.size_x)
            height = int(bbox.size_y)

            x1 = center_x - width // 2
            y1 = center_y - height // 2
            x2 = center_x + width // 2
            y2 = center_y + height // 2

            # Get class and confidence
            class_id = detection.results[0].hypothesis.class_id
            score = detection.results[0].hypothesis.score

            # Draw bounding box
            cv2.rectangle(img, (x1, y1), (x2, y2), (0, 255, 0), 2)
            cv2.putText(
                img,
                f"Class {class_id}: {score:.2f}",
                (x1, y1 - 10),
                cv2.FONT_HERSHEY_SIMPLEX,
                0.5,
                (0, 255, 0),
                2
            )

        # Publish annotated image
        self.image_pub.publish(self.bridge.cv2_to_imgmsg(img, 'bgr8'))

def main():
    rclpy.init()
    node = DetectionVisualizer()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()
```

## NITROS - Zero-Copy Transport

**NITROS** (NVIDIA Isaac Transport for ROS) eliminates memory copies between nodes, enabling single-digit millisecond latency.

### How NITROS Works

```
Traditional ROS 2:
┌─────────┐  serialize   ┌────────┐  deserialize  ┌─────────┐
│ Node A  │ ──────────> │  DDS   │ ────────────> │ Node B  │
└─────────┘   (copy 1)  └────────┘    (copy 2)   └─────────┘

NITROS:
┌─────────┐  GPU pointer  ┌────────┐  GPU pointer  ┌─────────┐
│ Node A  │ ───────────> │ Shared │ ───────────> │ Node B  │
└─────────┘   (no copy)  │ Memory │   (no copy)   └─────────┘
                         └────────┘
```

**Benefits:**
- **Latency:** 0.5-2ms (vs. 10-50ms for traditional)
- **Throughput:** 10x higher bandwidth
- **Power:** Lower CPU usage (GPU-to-GPU transfers)

### Using NITROS in Custom Nodes

```cpp
/**
 * nitros_node_example.cpp - Create NITROS-compatible node
 */
#include "isaac_ros_nitros_image_type/nitros_image.hpp"
#include "rclcpp/rclcpp.hpp"

class NitrosImageNode : public rclcpp::Node
{
public:
    NitrosImageNode() : Node("nitros_image_node")
    {
        // Subscribe with NITROS image type
        sub_ = create_subscription<nvidia::isaac_ros::nitros::NitrosImage>(
            "input_image",
            10,
            std::bind(&NitrosImageNode::callback, this, std::placeholders::_1)
        );

        // Publish with NITROS image type
        pub_ = create_publisher<nvidia::isaac_ros::nitros::NitrosImage>(
            "output_image",
            10
        );
    }

private:
    void callback(const nvidia::isaac_ros::nitros::NitrosImage::SharedPtr msg)
    {
        // Process image on GPU (zero-copy)
        // ... CUDA kernel processing ...

        // Publish processed image (still on GPU)
        pub_->publish(*msg);
    }

    rclcpp::Subscription<nvidia::isaac_ros::nitros::NitrosImage>::SharedPtr sub_;
    rclcpp::Publisher<nvidia::isaac_ros::nitros::NitrosImage>::SharedPtr pub_;
};

int main(int argc, char** argv)
{
    rclcpp::init(argc, argv);
    rclcpp::spin(std::make_shared<NitrosImageNode>());
    rclcpp::shutdown();
    return 0;
}
```
